# Design System — SIGES-PIN

## 1. Objetivo

Este documento define as diretrizes visuais e os padrões de interface do SIGES-PIN — Sistema Corporativo de Gestão do Portfólio de Inovação da BBTS.

O objetivo é manter a consistência visual entre as páginas, facilitar a reutilização de componentes e orientar a implementação de novas funcionalidades.

A referência visual principal é o projeto do Stitch:

https://stitch.google.com/projects/5689185856869447483

As definições deste documento devem ser comparadas com a referência visual e com o código real antes de serem consideradas definitivas.

## 2. Princípios visuais

O design do SIGES-PIN deve seguir os seguintes princípios:

- **Visual corporativo:** aparência profissional, organizada e adequada a um sistema institucional.
- **Clareza:** informações importantes devem ser facilmente identificadas.
- **Hierarquia visual:** títulos, indicadores, gráficos e ações devem ter níveis de destaque distintos.
- **Consistência:** componentes equivalentes devem utilizar os mesmos padrões visuais.
- **Simplicidade:** evitar elementos decorativos que prejudiquem a leitura.
- **Responsividade:** a interface deve funcionar em diferentes tamanhos de tela.
- **Acessibilidade:** cores, textos e controles devem facilitar a utilização por diferentes usuários.

## 3. Identidade visual

A interface utiliza uma identidade visual corporativa, com predominância de tons de azul, superfícies claras e cores de apoio para diferenciar indicadores e categorias.

Os elementos institucionais devem manter a identificação da BBTS e do SIGES-PIN sem competir visualmente com o conteúdo principal.

A identidade visual definitiva deve respeitar os materiais institucionais disponíveis e a referência aprovada para o projeto.

A tabela abaixo apresenta uma proposta inicial de cores funcionais, baseada na aparência geral da referência.

| Token | Cor de referência | Aplicação |
|---|---|---|
| `primary` | `#1D4ED8` | Botões principais, links e ações prioritárias |
| `primary-dark` | `#1E3A8A` | Destaques institucionais e estados mais escuros |
| `background` | `#F1F5F9` | Fundo da área principal |
| `surface` | `#FFFFFF` | Cartões, painéis e menus |
| `text-primary` | `#0F172A` | Títulos e textos principais |
| `text-secondary` | `#64748B` | Descrições e textos auxiliares |
| `border` | `#E2E8F0` | Bordas e divisórias |
| `success` | `#16A34A` | Estados positivos e indicadores de sucesso |
| `warning` | `#D97706` | Alertas e situações que exigem atenção |
| `danger` | `#DC2626` | Erros e situações críticas |
| `info` | `#0284C7` | Informações e estados informativos |
| `purple` | `#7C3AED` | Categorias ou indicadores secundários |
