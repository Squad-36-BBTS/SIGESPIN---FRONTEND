# SIGES-PIN — Dashboard Executivo (starter)

Starter front-end React + TypeScript + Vite + Tailwind CSS para a tela inicial do SIGES-PIN, baseado no código e nas referências compartilhadas na conversa.

> Os dados são demonstrativos. Este pacote não inclui o repositório local completo do usuário, integração com API/back-end, autenticação ou todas as telas do sistema.

## Requisitos
- Node.js (versão LTS recomendada)
- npm

## Executar
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Estrutura
```text
src/
  components/
    dashboard/
      ArenaChart.tsx
      MaturityRadar.tsx
    layout/
      Header.tsx
  pages/
    Dashboard.tsx
  App.css
  App.tsx
  index.css
  main.tsx
```
